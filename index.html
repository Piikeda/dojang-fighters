Como jogar
Mover← → andar · ↑ pular · ↖ ↗ (ou ↑ + ←/→) pular para trás / para frente
GolpesA jab · A A jab + direto · S direto (mão de trás) · D chute · F chute especial / giro · chute no ar = voadora
TécnicasSegure para trás para defender · ↓ → + D = chute giratório · JÚLIO, JÚLIO 2 e JÚLIO 3: ← + D = passo de costas + coice · → → + D = sobre passo + chute
ExtrasP ou ⏸ pausa · Enter confirma / continua · Esc volta à seleção · 1 mostra hitboxes
TreinoEscolha TREINO na primeira tela para chutar o BOB à vontade: sem tempo, sem nocaute e com contador de golpes.

No celular, use os botões na tela. No computador, clique uma vez no jogo para ativar o teclado.
