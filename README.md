# Dojang Fighters

Jogo de luta 2D de taekwondo para navegador, em HTML + JavaScript puro (canvas), sem dependências nem build.

## Como jogar
- Dê dois cliques no `index.html`, ou
- rode um servidor local nesta pasta: `python -m http.server 8000` e abra http://localhost:8000

## Controles
- ← → andar · ↑ pular · ↖ ↗ (ou ↑ + ←/→) pular para trás / para frente · segurar para trás = defesa
- A soco (A A = jab + direto) · S direto · D chute
- ↓ → + D e ← + D: golpes especiais · → → + D: sobre passo + chute
- P ou botão Pausa pausa · Enter confirma / continua
- Esc volta uma tela · 1 mostra as hitboxes

## No celular
Deite o celular: a luta ocupa a tela toda e os botões ficam por cima. O botão "Tela cheia" esconde a barra do navegador.

## Arquivos
- `index.html` — todo o código do jogo
- `*.webp` — sprites dos lutadores e cenários
